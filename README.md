# ⚔️ 地牢冒险 · 微信小游戏版

> 黑暗奇幻风地牢探索文字 RPG —— 微信小游戏（Canvas 渲染，无框架纯原生）

深入 25 层地牢，穿越五大主题区域，在双门抉择中步步为营：战斗、寻宝、交易、强化、迎战五头 Boss。

本仓库为 **minigame 分支**（微信小游戏版，Canvas 渲染）；小程序版（WXML 原生）在 **master 分支**。

---

## 🎮 玩法概览

### 探索
- 每层两扇门，选择前进路线——门后可能是：**怪物 / 宝箱 / 神秘商人 / 祭坛 / 陷阱 / 营地 / 死路 / 金币堆 / 磨刀石 / 旧齿轮**
- 点击门卡：选中卡放大 + 金色发光，另一卡缩小变半透明；怪物卡有专属缩放比例
- 事件进行中另一侧锁定，完成后原地生成新事件；**死路永久封锁**（防逃课）
- 探索状态持久化：退出重进恢复现场，无法刷门逃课
- 底部状态栏可展开/收起（平滑动画），展开显示商店/背包/铁匠铺/退出入口

### 战斗
- 回合制：攻击 / 防御（减伤 50%）/ 逃跑（有成功率，越逃失败概率越高）
- **暴击**（红字）、**闪避**（蓝字）、**中毒**（持续掉血）
- 词缀怪物：强壮 / 迅捷 / 暴虐 / 铁壁 / 剧毒 / 精英（攻防血加成）
- Boss 战：每 5 层一个 Boss，有专属技能
- 战斗日志可上下滑动翻看

### 成长
- 打怪升级：升级回复满血，属性成长
- **装备系统**：5 阶（tier）× 3 类（武器/护甲/饰品），主属性 + 副属性（暴击/闪避）
- **铁匠铺强化**：固定 50 金币起，每次强化 +50；每 5 层解锁 +1 强化上限；满级金色
- **神秘商人**：每主题 3 件主题商品（随主题变化），限量购买
- 祭坛献祭：消耗金币换永久加成（每主题 3 次上限）

> 每主题 5 种怪物（共 25 种），Boss 5 个。

### 装备（30 件：5 阶 × 3 类 × 2 件）
示例：
- 🗡️ 武器：木剑(攻+5) → 铁剑(攻+15) → 暗影之刃(攻+38 暴10%) → 龙魂巨刃(攻+78 暴10%)
- 🛡️ 护甲：布甲(防+3) → 板甲(防+16) → 龙鳞铠甲(防+32 闪8%) → 圣龙护甲(防+52)
- 💍 饰品：铜戒指(血+20) → 凤凰羽毛(血+130 闪10%) → 龙神之心(血+260) → 永恒龙晶(血+320 暴12%)

### 随机事件
宝箱（金币）/ 金币堆 / 神秘商人（主题商品）/ 祭坛（献祭加成）/ 陷阱（扣血可闪避）/ 营地（免费回复）/ 死路（永久封锁）/ 磨刀石（攻击+2）/ 旧齿轮（防御+2）

## 📁 项目结构

```
├── game.js                 # 小游戏入口：场景管理/触摸/存档
├── game.json               # 小游戏配置
├── app-icon.png            # 游戏图标（144×144 手绘金色交叉双剑）
├── js/
│   ├── ui.js               # Canvas 绘制工具（圆角/渐变/按钮/血条）
│   ├── explore.js          # 探索场景：双门抉择/事件卡/缩放动画/状态栏
│   ├── battle.js           # 战斗场景：回合制/词缀/Boss/日志滑动
│   └── panels.js           # 面板层：商店/背包/铁匠铺（可滚动列表）
└── utils/
    ├── game-engine.js      # 核心逻辑：Player/Monster/Battle/难度/词缀
    └── data.js             # 游戏数据：主题/怪物/Boss/装备/商人商品
```
