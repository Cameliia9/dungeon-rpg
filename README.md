# 🏰 地牢冒险 - 文字RPG微信小程序

一个暗黑风格的文字RPG冒险微信小程序，包含地牢探索、回合制战斗、装备收集和角色养成。

## 🎮 游戏系统

- **回合制战斗** — 攻击、防御（减伤50%）、逃跑（30%成功率）
- **升级养成** — 击杀怪物获取经验，升级提升属性并回满血
- **装备系统** — 武器(+攻击)、护甲(+防御)、饰品(+生命)，3个档位
- **地牢探索** — 每层3个随机事件房间：怪物、宝箱、陷阱、休息点、装备掉落
- **自动存档** — 本地存储，每次操作自动保存

## 🚀 快速开始

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 注册小程序账号获取 AppID: https://mp.weixin.qq.com/
3. 克隆项目：`git clone git@github.com:Cameliia9/dungeon-rpg.git`
4. 修改 `project.config.json` 中的 `appid` 为你的 AppID
5. 用微信开发者工具打开项目目录
6. 点击编译预览

## 📁 项目结构

```
├── app.js / app.json / app.wxss    # 小程序入口和全局样式
├── project.config.json              # 微信开发者工具配置
├── utils/
│   ├── game-engine.js               # 核心引擎（角色/战斗/事件/存档）
│   └── data.js                      # 游戏数据（怪物/装备）
└── pages/
    ├── index/        # 主页：角色状态面板
    ├── explore/      # 探索：随机房间事件
    ├── battle/       # 战斗：回合制对战
    ├── inventory/    # 背包：装备管理
    └── shop/         # 商店：购买装备
```
