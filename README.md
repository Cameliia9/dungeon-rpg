# 地牢冒险 - 微信小游戏版

黑暗奇幻风地牢探索文字 RPG（微信小游戏，Canvas 渲染）

## 玩法
- 深入 25 层地牢，穿越五大主题区域（黏液沼泽/骸骨墓穴/暗影回廊/深渊火狱/龙之巢穴）
- 双门抉择：每层两扇门，选择前进路线，可能遇到怪物/宝箱/商人/陷阱/死路
- 战斗系统：暴击/闪避/词缀怪物（强壮/迅捷/暴虐/铁壁/剧毒/精英）/Boss 技能/中毒
- 成长系统：升级回复、装备 tier 分层、铁匠铺强化、神秘商人主题商品
- 三档难度：简单 ×1.0 / 困难 ×1.25 / 噩梦 ×1.5
- Boss 战：每 5 层一个 Boss（史莱姆之王/墓穴领主/死灵法师/深渊恶魔/远古邪龙）

## 项目结构
- game.js 小游戏入口（场景管理）
- js/ui.js Canvas 绘制工具
- js/explore.js 探索场景（双门+事件+状态栏）
- js/battle.js 战斗场景
- js/panels.js 面板层（商店/背包/铁匠铺）
- utils/game-engine.js 游戏核心逻辑（Player/Monster/Battle/难度/词缀）
- utils/data.js 游戏数据（主题/怪物/Boss/装备/商人商品）
